# Strong Number in C

## Description
This program checks whether a given number is a Strong Number by calculating the factorial of each digit and comparing their sum with the original number.

## Concepts Used
- `while` and `for` loops
- Factorial calculation
- Modulus and division operators
- Conditional statements

## Example
145 = 1! + 4! + 5! = 145

## How to Run
```bash
gcc strong_number.c -o strong_number.exe
./strong_number.exe
```

## Language
C
